# レギュレーションC

このページではレギュレーションCのルールについて記載します。
レギュレーションCは不屈・火事場を含め、スキルに制限がないルールです。

### 基本的なルール

- ソロプレイの記録であること
- オトモ・ダメージを与えるアイテム・拘束するアイテム・蔦上での戦闘は禁止
- 護石、装飾品、鎧玉、イベント防具などは全て使用可能
- 討伐すること

### 使用禁止アイテム及び装置

- 石ころ
- 罠肉
- 閃光玉
- 音爆弾
- 毒けむり
- 落とし穴
- シビレ罠
- 釣りカエル
- 投げナイフ
- 毒投げナイフ
- 麻痺投げナイフ
- 眠り投げナイフ
- 大タル爆弾
- 大タル爆弾G
- 打ち上げタル爆弾
- 打ち上げタル爆弾G
- ブーメラン
- 単発式拘束弾
- バリスタ
- 撃龍槍
- 対巨龍爆弾

※小タル爆弾は使用可能です。 (火事場運用を考えたときに、モンスターへの影響を与えないように制御することが難しい場合があるため、モンスターへ影響を与えることも認めることとします)

### 発動禁止スキル及びネコ飯

なし

### ニャンターについて
- サポート行動及びオトモスキルは全て使用可能とします。(罠、閃光、爆弾、背水の陣の術など)

### 備考
- 状態異常武器、弾、ビンは全て使用可能です。
- 音爆弾が有効なモンスターへの狩猟笛の高周波、ボウガンの榴弾についても使用可能です。
